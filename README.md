# ⏰ Time Zone Converter

A simple and intuitive mobile application built with React Native & Expo that allows users to quickly convert times across different global time zones.

## 🌟 Features

- 🌍 Select from 9 major time zones (NY, LA, London, Paris, Dubai, Kolkata, Tokyo, Sydney, Auckland).
- 🕒 Auto-fills the current time of the selected source time zone.
- 🔄 Converts time instantly when you press the button.
- 📱 Clean and responsive user interface.

## 🛠️ Tech Stack

- **Framework:** React Native (Expo)
- **Language:** JavaScript
- **Libraries:** Luxon (efficient timezone handling), React Native Picker (dropdown selection)
- **Web Support:** react-dom, react-native-web
