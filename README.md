# 🛒 E-Commerce Marketplace App

A fully functional mobile e-commerce application built with React Native & Expo as part of my Android App Development internship at **Arch Technologies**.

Users can browse products, add items to their cart, simulate payment, and list their own products for sale – all in a clean, user-friendly interface.

---

## 📱 Features

- ✅ **User Authentication** – Login with any email and password (demo mode)
- ✅ **Browse Products** – View all listed products with title, price, description, and seller
- ✅ **Buy Products** – Add items to cart and proceed to checkout
- ✅ **Sell Products** – List your own products for others to purchase
- ✅ **Shopping Cart** – View cart items and total price
- ✅ **Payment Simulation** – Checkout with a simulated payment success screen
- ✅ **Logout** – Securely log out and return to login screen

---

## 🛠️ Tech Stack

| Technology | Purpose |
|------------|---------|
| React Native | Cross-platform mobile app framework |
| Expo | Development platform |

| FlatList | Efficient product listing rendering |
| React Native Components | Core UI building blocks |

### Prerequisites
- Node.js installed
- Expo CLI installed globally (`npm install -g expo-cli`)
- Expo Go app on your mobile device
